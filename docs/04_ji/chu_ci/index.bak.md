# 楚辭  

### 【戰國】屈原 等 著

---

</div>

!!! note "書籍解題"
    《楚辭》為戰國時期楚國詩歌總集，以屈原作品為主，並收錄宋玉等人之作。其形式打破了《詩經》四言體制，運用楚地方言與民歌句式，開創了中國浪漫主義文學之先河。
